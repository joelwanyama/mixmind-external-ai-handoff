MixMind Intrinsic Lite Pair Scan — Phase 3 Foundation

Purpose
This adds a read-only “Scan Lite Pairs” button beside Analyze Lite Activity.
It scans every directed pair among the loaded library tracks with the same Lite
gate used by QC. It does not apply fallbacks, alter locks, start playback, or
prepare stems.

Result categories
- LITE CANDIDATE: gate passed using current intrinsic evidence.
- MASTER ONLY: a hard current gate reason is shown.
- NEEDS ACTIVITY: Lite activity evidence is missing.
- INVALID MAPPING: a source-time mapping diagnostic failed.

Install
1. Stop MixMind.
2. Extract this ZIP into the main MixMind folder and replace files.
3. Start MixMind and press Ctrl + Shift + R.
4. Click Analyze Lite Activity if any song says it needs activity.
5. Click Scan Lite Pairs.
6. Send a screenshot of the results panel.

This is a Phase 3 foundation. It uses the selected current safe pair per directed
pair; the later full candidate landscape/nearest-miss interface is still separate work.
