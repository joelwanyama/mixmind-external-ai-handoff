MixMind Plan History — Phase 11

Adds a Plan History button beside Scan Lite Pairs. It lists automatic sealed-plan
snapshots saved in this browser, compares their saved track metadata/timeline
order to current state, and permits downloading the latest JSON snapshot.

It is read-only. It does not restore, modify, or force a plan. If no snapshot
exists yet, it explains that the next sealed candidate will be saved automatically.
