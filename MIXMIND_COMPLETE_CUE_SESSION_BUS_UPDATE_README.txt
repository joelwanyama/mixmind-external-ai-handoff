MixMind Complete Cue Session Bus Update

This is a complete replacement bundle for the current tested diagnostic path.
Use this ZIP instead of applying several small cue updates separately.

It includes:
- source/local time-coordinate repair;
- playable safe-window ranges;
- protected full-interval vocal evidence;
- intrinsic pair scan and candidate landscape;
- sealed Lite test plans;
- bounded cue test;
- cue-session output bus isolation;
- cue output connection/RMS panel fields.

Installation
1. Let any currently playing cue finish, or close MixMind.
2. Stop the black local-server window with Ctrl+C.
3. Extract this ZIP.
4. Copy EVERY extracted file directly into the one main MixMind folder that
   contains START_MIXMIND_WINDOWS.bat and index.html.
5. Choose Replace files for every prompt.
6. Start MixMind from that same folder.
7. Press Ctrl+Shift+R in the browser.

Verification before testing
After Scan Lite Pairs -> Seal Lite Test Plan -> Start / Restart, the cue panel
MUST show both lines:
  Cue output connected: yes/no
  Cue RMS: 0.xxxxx

If those two lines do not appear, this is not the folder served by the local
server. Do not test Stop; first locate the folder containing the START_MIXMIND_WINDOWS.bat file actually used to start MixMind.
