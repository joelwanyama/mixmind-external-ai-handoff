MixMind Sealed Lite Test Plan — Phase 5

This adds “Seal Lite Test Plan” for an intrinsic Lite candidate. The button
creates an immutable, in-memory diagnostic plan containing its exact source
starts, effective drift-limited overlap, gate result, policy versions, source
budget (3), and prebuilt Master fallback.

It does NOT start Lite playback, change normal Master playback, alter any stored
transition, clear locks, export audio, or apply a fallback.

Install, Ctrl+Shift+R, click Scan Lite Pairs, then click Seal Lite Test Plan for
one candidate. Send a screenshot of the success toast showing the plan ID.
